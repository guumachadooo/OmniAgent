- **Real Stack vs. Preview Shim:** Product is **C#/.NET (`net11.0-android`)** (`OmniAgentAndroid/`), **Cloudflare Unified Hub v6 Worker** (`worker/cloudflare_live_relay_worker.js`), & **Python 3 stdlib bridge/daemon** (`agent/`). NEVER delete C#/Python/Worker files or add web deps.
- **Host-Aware Boot (`host-boot` via `.agents/host_matrix.json`):**
  1. Run `python3 -B .agents/plugins/dynamic-fractal-planner/scripts/plan_tool.py host-boot` (auto-detects `antigravity-termux` vs `ai-studio-cloud` vs `ci-runner` vs `local-ide`):
     - **On `ai-studio-cloud`:** run `python3 -B agent/flight_recorder.py recover && python3 -B agent/omni_agent_client.py capabilities && python3 -B agent/omni_agent_client.py repos status`; symlink `/tmp/cavern-federation/omniagent -> /app/applet` & hydrate `cavern`/`fractal` (`repos hydrate`); if `GITHUB_TOKEN` absent -> `python3 -B agent/omni_agent_client.py connect --scope workspace` (1-tap S25U Biometric Smart Knock via `.agents/bridge_profile.json`).
     - **On `antigravity-termux` (local S25U PRoot):** skip `flight_recorder`, `preview/` shim, `live_sync_watcher`, & AI Studio `missingExpectedVars` alerts (preserve intact for AI Studio!); use native `git`, `gh`, filesystem, `/root/.dotnet/dotnet`, & local `/root/.gemini/antigravity/scratch/{Cavern,OmniAgent,dynamic-fractal-planner}`; reserve `omni_agent_client.py` strictly for Android IPC (`cavernize-cmd`, `hot_exec`, `logcat`, auth via `~/.omni_agent/config.json`).
